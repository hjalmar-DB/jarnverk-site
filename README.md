# Járn verktakar ehf. — jarnverk.is

Stöðuvefur með nokkrum síðum. Engin byggingarþrep. Hýstur á Render. Render birtir aðeins `public/`, sem `node scripts/publish.mjs` fyllir. Minnisskrár (*.md) og stillingar fara ekki á vefinn.

This is a multi-page static site. It needs no build step. It is hosted on Render, which serves only `public/` (filled by `node scripts/publish.mjs`). Notes (*.md) and config are not published. Security headers are in `render.yaml`.

- `/` Forsíða
- `/thjonusta/` Þjónusta
- `/verkefni/` Verkefni
- `/taekjakostur/` Tækjakostur
- `/um-okkur/` Um okkur
- `/hafa-samband/` Hafa samband
