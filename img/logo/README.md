# Járn – logo files (vector recreation of the client's logo)

Traced from the client's 2015 PDF print (phone screenshot), then rebuilt as SVG. Diamond and inner border are exact geometry; pickaxe/spade and the JÁRN letters are traced outlines (converted to paths, no fonts needed).

Colours: yellow #F0DF28 (sampled), black #1C1B1A (sampled), white #FFFFFF for the dark version.

| File | Use |

| logo-full-on-dark.svg / logo-full-on-dark-1200.png | Same, JÁRN in white (icon unchanged) |
| logo-icon.svg / logo-icon-512.png / logo-icon-1024.png | Icon only |
| logo-horizontal.svg / logo-horizontal-1600.png | Icon left, JÁRN right (black wordmark) |

| favicon.svg, favicon.ico (16/32/48), favicon-32/48/192.png, apple-touch-icon.png | Favicons |
| logo-compare.png | Original vs. SVG side by side |

PNGs are transparent except apple-touch-icon.png (white background).
In the horizontal versions the wordmark is scaled larger relative to the icon than in the full lockup, and no "Verktakar" line is added, because the original has none.
